One image that sums up the world news of Saturday 21 November 2026, built as a newspaper-style front page: a date banner over four captioned editorial illustrations, one per story — the Shenzhen summit where the US, Chinese and Russian leaders met; a Russian missile coming down in Poland during the strikes on Ukraine; the World Court's ruling that Myanmar committed genocide against the Rohingya; and the COP31 climate talks deadlocked with no deal in sight. The four panels (in panels/) were drawn with an image model in a shared flat editorial style, and build_entry.py composes them with the banner and captions so every word is crisp. main.py hands the finished image in.

## Run it

```sh
python3 main.py
```
